与meow星事

meow，取谐音：星球的「星」，事情的「事」。

这里还在等大家来喵一回——故事收集中。这一页先放一下，等故事来了再填满。

这里是谱写故事的地方。

请带猫、捡猫的人来「喵一回」：投稿分享自己跟猫的互动，说说当时的事。 一只猫是怎么来到小院的，当时发生了什么，你还记得吗？把你的故事写下来，我们放在这里。

下面是小院里的 14 只猫。每一只背后都有一个人，和一段还没写下来的事。 如果你是那个人，欢迎来喵一回。

  1. 呦唬——FC 遇到的第一只猫。 它的故事已经写在Meow传了：去年 10 月，一只猫闯进了一个人的出差生活。
  2. 咪咪——月月（杨文月）从家里带来的黑猫。 月月，来说说你把咪咪带来小院的那天。
  3. 图图——艺术共创营期间来的猫。 谁还记得它是怎么来的？欢迎来喵一回。
  4. 芝麻——艺术共创营期间来的猫。 谁还记得它是怎么来的？欢迎来喵一回。
  5. 蛋黄——文月收养的猫。 文月，来说说你收养蛋黄的那天。
  6. 心祈貳、心祈寺、心祈伍、心祈陸、心祈日——呦唬的五只孩子。 看着它们长大的人，欢迎来写写它们。
  7. 奶香泡——白腹黄背的猫。 谁知道它是怎么来的？欢迎来喵一回。
  8. 马泡——伦峰老师在南塘小住期间捡的猫，后脚双腿瘫痪，只能用前二脚爬行。 伦峰老师，来说说你捡到马泡的那天。
  9. 小黄豆——刘姨家猫生崽后送来的深橘小猫。 刘姨，来说说你把家里最后一只小猫送来小院的那天。
  10. 黑熊——文君带来的猫，很黏人，穿着黑披肩的白底猫。 文君，来说说你把黑熊带来小院的那天。

怎么投稿

投稿就是文字内容：把你的故事写下来，不用长，几句话也可以。写你和猫的互动，说说当时的事。 不用会画画，不用会拍照，文字就够了。

写好了，发到 GitHub Issue，或直接告诉 FC，由我们放上来。 不会用 GitHub 也没关系，告诉 FC 就行。
